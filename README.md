# 월간 MY GOD — 웹 프로토타입

서사형 1:1 오컬트 TCG 《월간 MY GOD》의 웹판 프로토타입입니다.
상대 체력을 깎는 게임이 아니라, **내 강림 트랙(잠복 → 조짐 → 현현, 마녀만 +승천)을 먼저 완주하는 레이스**입니다.

- 플레이 가능: 다섯 신도 전원 — **인내(한영일) · 마녀(서다인) · 영원(백지우) · 욕망(이하니) · 무위(김민수)**. 미러전과 AI끼리 관전도 됩니다.
- 영원은 카드풀 표를 그대로 옮겼고, **욕망·무위는 기획서에 정확값이 없어 덱 컨셉 브리프(욕망)와 시스템서 §7 권능 예시(무위)를 바탕으로 웹판에서 임시 설계**했습니다. 해당 카드는 데이터에 `"draft": true`, 화면에 「임시」 배지가 붙습니다.
- 보스(이름 없는 신)는 기획서상 미설계라 아직 없습니다.
- 아트는 플랫·라인리스 결의 SVG 플레이스홀더입니다 (`src/ui/art.ts`에서 교체).

## 실행

```bash
npm install
npm run dev        # 로컬 개발 서버
npm test           # 규칙 테스트 + 다섯 신 모든 매치업 AI 대전이 끝나는지
npm run sim        # 밸런스 표 — 매치업별 AI 대 AI 승률·평균 턴 (판 수: npm run sim -- 40)
npm run build      # dist/ 생성
```

`main`에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트 → 빌드 → GitHub Pages 배포까지 합니다.

## 구조

```
src/
  engine/          순수 규칙 로직 — React를 모른다
    types.ts         카드·효과·상태 타입 (카드 기획서 effects 스키마의 웹판)
    db.ts            카드·신·덱 로더 + BALANCE 수치
    rules.ts         5페이즈·두 방·습격·죽음 트리거·권능·강림 판정. applyAction(state, action) → state
    ai.ts            평가함수 기반 그리디 AI (한 수 앞 + 이동→권능 두 수)
  data/            엔진이 읽는 데이터 (코드 아님)
    cards/*.json     중립·인내·마녀·영원(카드풀 표 그대로) + 욕망·무위(임시 설계)
    gods.json        신·권능 단계·문턱·그릇
    decks.json       30장 기본 덱
  ui/              표시 계층 — 엔진 상태를 그리기만 한다
    theme/tokens.css 디자인 토큰 (색·글꼴·간격·모션) ← 재디자인 출발점
    components/      CardFace, UnitToken, GodPanel, DescentTrack, RaceMeter, FxLayer …
    screens/         TitleScreen(표지), MatchScreen(대전), GalleryScreen(도감)
```

규칙 수치(문턱·그릇·슬롯·손패)는 `src/engine/db.ts`의 `BALANCE`와 `src/data/gods.json`에서, 카드는 `src/data/cards/*.json`에서 바꿉니다. 코드 수정은 필요 없습니다.

## 기획서에서 정하지 않은 부분 — 이 웹판의 해석

| 항목 | 해석 |
|---|---|
| 소환된 유령 | 소환된 턴에도 옮길 수 있음 (카드기획서 §9-2 `acted=false`) |
| 《잊혀진 창립 멤버》 각성 | 현현부터 매 턴 시작, 유령이 있으면 OP +1 |
| 《다인시아의 그림자》 각성 | 현현부터, 내가 희생할 때마다 상대 성역에서 가장 빈사인 신도에 1 피해 |
| 《마력 방출》 피해 대상 | 상대 성역에서 가장 빈사인 신도로 자동 지정 |
| 《비상 소집》 | 유령 하나가 즉시 봉헌 (그 봉헌력만큼 OP) |
| 성지 비용 | 기획서에 없던 것: 24시 사옥 3, 사내 추모비 2, 노동조합 4, 마법진 2, 피의 제단 2, 다인시아의 탑 4 |
| 플레이버 | 인내·마녀 신도·의식 대부분, 영원 신도 전부, 욕망·무위 전부의 플레이버는 임시로 써 넣은 것 (중립·《만년 대리》·영원 의식/성지는 기획서 원문) |
| 멀리건 | 아직 없음 |
| 트리거 순서 | 죽은 신도 자신 → 소유자 성지 → 소유자 다른 신도(uid순). 연쇄는 깊이 우선 |
| 병실 무덤 (영원) | = 묘지(죽은 신도·쓴 의식·버린 카드) + 「병실 N장 채움」 덤. 되살리면 그 카드는 병실을 떠난다 |
| 《병실》 성지 | 내 신도가 죽을 때 1장 더 (그 죽음이 2장으로 친다). 《병실 친구》·《박제된 순간》의 「2장 채움」은 2장 더 |
| 《영원의 순간》 | OP += 현재 문턱 → 그 턴 끝 판정에서 한 단계 상승 (매 턴 한 단계). 영원 성지 비용(제단 3·병실 2·시계탑 3)은 임시 |
| 되살림 | 일상으로 돌아오며, 그 턴엔 성역에 못 간다. 일그러진 되살림 = 목숨 1 |
| 의존 대상 (욕망) | 권능·카드로 지정. 지정한 신도가 봉헌하면(어느 편이든) 조짐부터 나도 OP. 대상이 죽으면 「이별」→ 얼굴이 오열 |
| 무위 권능 | 지속형, 단계가 오를수록 효과가 쌓인다: 잠복 습격 피해 -1 → 조짐 상대가 카드 낼 때 OP +1(턴당 1회) → 현현 상대 봉헌 -1 |

## 밸런스 메모

### 조정 로그 (v0.3 — 가벼운 밸런싱)

| 구분 | 바꾼 것 | 왜 |
|---|---|---|
| 새 규칙 | **「헌납」** — 준비 페이즈에 턴당 1회, 손패 1장을 바쳐 이번 턴 신앙심 +1 (카드는 묘지/병실로) | 손패가 과하게 남는 문제. 원인은 신앙심 부족(특히 인내 23~54%)과 일상 자리 부족(신도 카드가 죽은 패가 됨). 못 내는 카드를 연료로 바꾸는 출구 |
| 후공 보정 | 첫 턴 신앙심 +1 → **+ 시작 손패 1장** | 다섯 신 미러 120판 기준 선공 승률 48% (편차 해소) |
| 영원 | 잠복 권능에 **「매 턴 시작, 덱 맨 위 1장이 병실로 흘러간다」** (전 단계 유지) | 삼종 유품 퀘스트가 드로우 운에 묶여 완성률 46%·평균 11.5턴 → 83%·6.8턴 |
| 영원 | 《영원의 제단》 아래에선 쓴 《영원의 순간》이 **손으로 돌아온다** | 제단이 봉헌을 영구 봉쇄하는데 《영원의 순간》이 2장뿐이라 세 번째 단계를 영영 못 채우는 함정. 덱 컨셉의 "반복 도약" 관찰 항목을 성립시키는 해석 |
| 욕망(임시) | 권능의 봉헌 흡착은 **의존 대상이 상대 신도일 때만**(기생). 현현 흡착 +1 | 내 신도에게도 흡착되어 두 번 먹는 구조였음 → 브리프의 🅰 자가발전 ↔ 🅱 기생 시소가 실제로 갈리게 |
| 욕망(임시) | 《애인 납치》 5→6, 《질투》 2→3 | 과강 |
| 무위(임시) | 현현 「다 같이 무의미해지자」 상대 봉헌 -1 → **-2**. 《방구석 이불》 2→1, 《택배 상자 탑》 3→2, 《분탕 치기》 3→2, 《가능성으로만 남은 사람》 3→2 | 과약 |
| AI | 위협 계산에 "다음 턴 성역으로 걸어 들어올 상대 일상 신도"를 포함, 헌납 사용, 영원 유품·《영원의 순간》 가치 평가 | AI가 인내를 너무 못 굴려서(벽을 안 세움) 시뮬이 인내를 과소평가했음 — 실제로 해 보면 인내가 더 낫다는 피드백과 맞춤 |
| AI (v0.3.1) | "일상이 꽉 차서 손패 신도가 못 나오는 손해"를 평가에 넣고, 마녀의 성역 신도를 제물로서 더 높게 침 | 서다인 AI가 신도를 성역에 안 보내던 문제(턴의 59%를 성역 빈 채로 끝냄 → 25%). 마녀 덱이 설계대로 성역을 굴리게 됨 |

인내·마녀 카드풀 수치는 그대로입니다.

### 현재 승률

`npm run sim -- 40` (매치업당 40판, 미러 제외 전체 승률, v0.3.1 AI):

| 서다인(마녀) | 이하니(욕망) | 한영일(인내) | 백지우(영원) | 김민수(무위) |
|---|---|---|---|---|
| 63% | 58% | 48% | 31% | 29% |

- 서다인 AI가 성역을 제대로 쓰기 시작하자 마녀가 가장 세졌습니다. 시뮬로 확인해 보니 **문턱(8→9, 9/11/12/14)이나 「검은 제물」 비용(2→3)을 올려도 승률이 거의 그대로**(76→75~78%)입니다. 마녀의 힘은 희생보다 습격 3짜리 신도들의 압박에서 나옵니다 — 손본다면 카드풀 습격력 쪽이고, 이건 정본 수치라 기획 판단으로 남겨 둡니다.
- 같은 AI 개선이 마녀·욕망의 자리 돌리기를 도와서 영원·무위가 상대적으로 내려갔습니다.

- AI 대 AI 기준이라 사람이 하면 다릅니다. 특히 그리디 AI는 여러 턴짜리 계획(영원의 퀘스트, 욕망의 지정 운영)을 사람보다 못 굴립니다.
- 욕망·무위는 임시 설계라 수치 자체가 확정 전입니다.
